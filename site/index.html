    Settings

    Kept only for this browser tab (sessionStorage); closing the tab forgets it. Create a key at openrouter.ai/keys. A dedicated key with a credit limit is safest.

    Pick a suggestion or type any OpenRouter model ID. openrouter/free and IDs ending in :free cost nothing but are rate-limited.

    About security
    • Your key is sent from this browser directly to OpenRouter. This site has no server and never sees it, but any script running on this page could.
    • The key is kept only for this tab (sessionStorage). Pages on the same github.io origin can read storage, which is why it is not saved on the device.
    • Replies are shown as plain text and are never interpreted as HTML.
    • If you think a key was exposed, revoke it at openrouter.ai/keys.
